# Feature card: Dashboard unslop

## Outcome and acceptance

Make the first dashboard easier to scan by quieting decorative surfaces while preserving information, order, controls, demo labeling and device safety states. Existing navigation and responsive behavior remain intact.

## Scope and risks

- UI only: dashboard presentation; no API, database, data, or deployment changes.
- Preserve botanical palette, current components and truthful empty states. Browser visual and keyboard verification depend on browser availability.
- Direction: operators monitor greenhouse conditions; calm, clear, practical; greenhouse instruments; data and alerts carry emphasis; greenhouse context remains the signature.

## Order and ownership

1. Main agent (frontend): remove misleading hover and reduce nested decorative backgrounds.
2. Main agent (QA): targeted UI tests, lint, typecheck, build, and diff review; document visual QA limitations.
