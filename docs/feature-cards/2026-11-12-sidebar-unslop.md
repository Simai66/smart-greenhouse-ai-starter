# Feature card: Sidebar refinement

## Outcome and acceptance

Make the sidebar quieter and easier to scan while retaining its logo, greenhouse context, status, navigation order, selected state, and mobile behavior.

## Scope and risks

- UI only: sidebar spacing and typography; no API, database, or deployment changes.
- Keep the established botanical palette and selected white surface. Browser visual QA is unavailable unless the browser connection recovers.

## Order and ownership

1. Main agent (frontend): refine existing sidebar without changing behavior.
2. Main agent (QA): lint, targeted tests, diff review, and report visual QA limitations.
