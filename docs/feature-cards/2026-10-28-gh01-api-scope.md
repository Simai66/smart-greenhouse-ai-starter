# Feature card: GH-01 API pilot boundary

**Status:** Implemented locally; local tests/build/lint pass. Staging verification
blocked because `CLOUDFLARE_API_TOKEN` is unavailable in this environment.

## Outcome and acceptance

Only GH-01 is available through greenhouse APIs during the single-greenhouse
pilot. Authenticated browser reads/writes and signed agent operations targeting
another greenhouse return HTTP 403 before reading or changing its data. Image
completion also rejects an image outside GH-01 before storage access. Existing
role checks, input validation, and GH-01 behavior remain intact.

## Contract

- Browser APIs with a supplied greenhouse ID reject any value other than
  `GH-01` with `{"error":{"code":"GREENHOUSE_FORBIDDEN","message":"Only GH-01 is available in the pilot."}}`
  and status 403.
- Invalid/missing inputs keep their existing 400 responses. Sensor config by
  opaque sensor ID returns existing 404 when the sensor is outside GH-01.
- Signed agent APIs reject non-GH-01 after signature/envelope validation and
  before D1 reads/writes. Image completion reads only the image metadata needed
  to determine its greenhouse, then rejects before storage access. Agent
  registration checks remain required.
- Existing data and demo behavior are unchanged. No claim that data is live.

## Scope

- **In:** Shared scope check; browser sensor, plant, device point/assignment/
  policy, command and image APIs; agent registration guard; browser/agent image
  reservation and completion; focused tests and docs.
- **Out:** Membership schema, user/role changes, D1 migration, UI/live-mode,
  hardware, deployment, remote data, and actuator enablement.
- **Risks/assumptions:** User selected GH-01 as the only pilot. Authenticated
  users still rely on existing global email roles and hosted Access policy.
  Staging and physical sensor proof remain separate release gates.

## Owners and order

1. Backend (main agent): add contract and shared boundary, apply to every

2. QA (main agent): verify GH-01 allow, foreign greenhouse deny, role/input
